# 数据中心架构文档

## 概述

数据中心（DataCenter）是Homalos交易系统的核心数据处理模块，负责7x24小时运行，提供全市场期货合约的实时行情数据订阅、持久化存储和历史数据查询服务。

## 架构设计

### 核心职责

1. **独立运行**：7x24小时稳定运行，不受其他服务模块影响
2. **全市场订阅**：自动订阅所有期货合约的实时tick行情数据
3. **数据持久化**：将tick数据持久化到SQLite和Parquet格式
4. **K线合成**：基于历史tick数据合成多周期K线数据
5. **历史查询**：为其他服务模块提供tick和bar数据的历史查询功能
6. **数据服务**：为数据服务、回测引擎等模块提供数据支持

## 核心模块

### 1. 数据库管理器 (DatabaseManager)

**功能**：
- SQLite数据库管理（tick_data, bar_data表）
- Parquet文件管理（按日期分区）
- 批量写入优化
- 索引管理

**特性**：
- WAL模式提高并发性能
- 异步批量写入
- 内存缓存机制
- 自动备份和恢复

### 2. K线合成器 (BarGenerator)

**功能**：
- 基于tick数据合成K线
- 支持多周期：1m, 5m, 15m, 30m, 1h, 4h, 1d
- 实时和历史数据合成

**算法**：
- 时间窗口聚合
- OHLCV计算
- 成交量加权平均价格

### 3. 行情订阅管理器

**功能**：
- 全市场合约自动订阅
- 订阅状态监控
- 重连和重试机制
- 交易时间判断

**配置**：
```yaml
market_subscription:
  auto_subscribe_all: true
  retry:
    max_attempts: 5
    initial_delay: 1
    max_delay: 60
```

### 4. 查询服务

**功能**：
- tick数据历史查询
- bar数据历史查询
- 分页和限制支持
- 时间范围过滤

**API**：
- `query_tick_data(symbol, start_time, end_time, limit)`
- `query_bar_data(symbol, interval, start_time, end_time, limit)`

## 数据流程

### 1. 实时数据流

```
CTP网关 → 原始Tick → 数据验证 → 批量缓存 → 异步写入 → SQLite/Parquet
                                    ↓
                              K线合成 → Bar数据 → 存储
                                    ↓
                              事件分发 → 其他服务模块
```

### 2. 历史查询流

```
查询请求 → 参数验证 → 数据库查询 → 结果处理 → 事件响应
```

## 性能优化

### 1. 批量写入

- **Tick数据**：1000条/批次，5秒刷新
- **Bar数据**：500条/批次，10秒刷新
- **内存限制**：Tick 100MB，Bar 50MB

### 2. 异步处理

- 多线程写入队列
- 异步事件处理
- 非阻塞查询

### 3. 缓存策略

- **内存缓存**：最近数据快速访问
- **LRU淘汰**：自动清理过期数据
- **预加载**：常用数据提前加载

## 配置说明

### 主要配置文件

1. **data_center_config.yaml**：数据中心主配置
2. **market_symbols.json**：市场合约配置
3. **holidays.json**：节假日配置

### 关键配置项

```yaml
# 批量写入配置
batch_write:
  tick:
    batch_size: 1000
    flush_interval: 5
    
# 性能配置
performance:
  cache:
    tick_cache_size: 10000
  async:
    max_workers: 4
    
# 数据保留策略
retention:
  tick_data:
    days: 30
    archive_days: 365
```

## 部署和运行

### 1. 独立启动

```bash
# 启动数据中心
python start_data_center.py
```

### 2. 服务模式

```bash
# Windows服务
sc create DataCenter binPath="python start_data_center.py"
sc start DataCenter

# Linux守护进程
nohup python start_data_center.py &
```

### 3. 监控检查

```bash
# 检查运行状态
curl http://localhost:8080/health

# 查看性能统计
curl http://localhost:8080/stats
```
