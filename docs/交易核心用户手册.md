## 快速入门

### 什么是交易核心？

交易核心（Trading Core）是 Homalos 量化交易系统的核心引擎，负责：

- 📡 **行情接收**：实时接收CTP行情数据
- 💹 **交易执行**：处理策略发出的交易信号
- 🔄 **事件驱动**：高性能事件总线（EventBus）
- 📊 **数据处理**：K线生成、订阅管理
- 🛡️ **风险控制**：实时风控监控
- 🎯 **策略运行**：独立进程隔离运行策略

### 5分钟快速上手

```bash
1. 启动Web服务
   start_all_web.bat

2. 访问Web界面
   http://localhost:5173

3. 登录系统
   用户名: admin
   密码: admin123

4. 登录资金账户
   点击"登录资金账户" → 选择券商 → 输入账号密码

5. 启动交易核心
   控制台 → 点击"启动核心(自动连接)" → 等待状态变为"运行中"

6. 管理策略
   策略管理 → 加载策略 → 启动策略
```

## 启动交易核心

### 方式一：自动连接模式（推荐）

**操作步骤**：

1. 进入**控制台**页面
2. 点击**"启动核心(自动连接)"**按钮
3. 等待状态变为**"运行中"**（约5-10秒）
4. 确认网关状态全部显示 ✓

**状态流转**：
```
已停止 → 初始化中 → 连接中 → 运行中
```

**自动连接流程**：
- ✅ 启动8个核心模块（EventBus、网关、风控等）
- ✅ 自动连接行情网关
- ✅ 自动连接交易网关
- ✅ 自动完成结算确认
- ✅ 自动加载合约信息

### 方式二：手动连接模式

**操作步骤**：

1. 点击**"启动核心"**（不自动连接）
2. 等待状态变为**"运行中"**
3. 点击**"连接网关"**按钮
4. 等待网关状态全部显示 ✓

**适用场景**：
- 需要先配置核心参数
- 分步骤验证核心启动
- 调试模式

### 核心状态说明

| 状态 | 颜色 | 说明 | 操作 |
|------|------|------|------|
| **已停止** | 灰色 | 核心未启动 | 可以启动 |
| **初始化中** | 橙色 | 正在初始化模块 | 请等待 |
| **连接中** | 橙色 | 正在连接CTP网关 | 请等待 |
| **运行中** | 绿色 | 核心正常运行 | 可以停止/管理策略 |
| **停止中** | 橙色 | 正在停止核心 | 请等待 |
| **错误** | 红色 | 启动失败 | 查看错误信息 |

## 连接CTP网关

### 网关状态指标

交易核心包含4个网关连接指标：

| 指标 | 说明 | 成功标志 |
|------|------|----------|
| **行情网关** | 行情数据接收 | ✓ |
| **交易网关** | 交易指令发送 | ✓ |
| **结算确认** | 结算单确认 | ✓ |
| **合约加载** | 合约信息加载 | ✓ |

**完整连接状态**：所有4个指标都显示 ✓

### 网关配置

核心使用的网关配置来自 `config/brokers.yaml`：

```yaml
simnow7x24:
  broker_name: "SimNow模拟（7x24）"
  broker_id: "9999"
  md_address: "tcp://180.168.146.187:10211"  # 行情地址
  td_address: "tcp://180.168.146.187:10201"  # 交易地址
  app_id: "simnow_client_test"
  auth_code: "0000000000000000"
```

**默认使用**：`simnow7x24`（7x24小时测试环境）

**切换环境**：修改 `config/system.yaml` 中的 `enable_broker`

### 断开网关

**操作步骤**：

1. 确认核心状态为**"运行中"**
2. 点击**"断开网关"**按钮
3. 等待网关状态全部变为 ✗

**注意事项**：
- ⚠️ 断开网关后，策略将无法接收行情和交易
- ⚠️ 已运行的策略不会自动停止
- ⚠️ 断开后可随时重新连接

## 策略管理

### 加载策略

**方式一：加载全部策略**

1. 进入**策略管理**页面
2. 点击**"加载全部"**按钮
3. 系统自动扫描 `src/strategy/strategies/` 目录
4. 将所有策略加载到管理列表

**方式二：加载单个策略**

1. 点击**"加载单个"**按钮
2. 在弹窗中选择策略文件（如 `strategy1.py`）
3. 确认加载
4. 策略出现在管理列表中

**策略注册**：
- 新策略默认 `enabled=true`
- 之前卸载的策略恢复原 `enabled` 值
- 所有策略配置保存在 `strategy_registry.json`

### 启动策略

**前置条件检查**：

1. ✅ 交易核心已启动
2. ✅ CTP网关已连接
3. ✅ 策略 `enabled=true`

**操作步骤**：

1. 找到要启动的策略
2. 点击**"启动"**按钮
3. 等待状态变为**"运行中"**
4. 观察实时日志

**状态流转**：
```
未启动 → 启动中 → 运行中
```

**核心未运行时**：
- 系统会显示警告提示
- 提供"前往控制台"按钮
- 不允许启动策略

### 停止策略

**操作步骤**：

1. 找到正在运行的策略
2. 点击**"停止"**按钮
3. 确认停止操作
4. 等待状态变为**"已停止"**

**自动停止**：
- 当交易核心停止时，所有运行中的策略会自动停止
- 系统会显示警告提示

### 卸载策略

**操作步骤**：

1. 确认策略已停止
2. 点击**"卸载"**按钮
3. 确认卸载信息
4. 策略从管理列表中移除

**卸载提示**：
```
确认卸载策略 xxx？
卸载后策略将从管理表格中移除，需要重新加载才可展示。
```

**重新加载**：
- 使用"加载全部"或"加载单个"功能
- 策略配置会从 `strategy_registry.json` 恢复

### 策略详情

点击策略名称可查看详细信息：

- **基础信息**：策略ID、名称、描述、作者
- **运行状态**：PID、启动时间、运行时长
- **订阅信息**：合约列表、K线周期
- **实时日志**：最近500条日志（实时更新）

## 常见问题FAQ

### Q1: 启动核心时提示"网关连接失败"？

**原因**：
- CTP服务器维护或非交易时间
- 网络连接问题
- 账号密码错误

**解决方案**：
1. 检查是否在交易时间内
2. 使用 `simnow7x24` 环境（24小时可用）
3. 确认账号密码正确
4. 检查网络连接

### Q2: 策略启动后没有收到tick数据？

**检查清单**：
1. ✅ 交易核心是否运行中？
2. ✅ CTP网关是否已连接？
3. ✅ 策略订阅的合约是否正确？
4. ✅ 是否在交易时间内？

**查看日志**：
- 后端日志：`logs/homalos_YYYYMMDD.log`
- 策略日志：策略管理 → 点击策略名称 → 实时日志

### Q3: 前端显示"网络错误，请检查连接"？

**可能原因**：
- Web服务未启动
- 浏览器缓存问题
- 后端异常

**解决方案**：
1. 确认 `start_web.bat` 正在运行
2. 强制刷新浏览器（Ctrl+Shift+R）
3. 查看后端日志是否有错误
4. 重启Web服务

### Q4: 如何切换CTP环境（模拟→实盘）？

**操作步骤**：

1. 修改 `config/system.yaml`：
   ```yaml
   enable_broker: "real"  # 改为实盘
   ```

2. 修改 `config/brokers.yaml`（添加实盘配置）：
   ```yaml
   real:
     broker_name: "实盘账户"
     broker_id: "你的券商ID"
     md_address: "实盘行情地址"
     td_address: "实盘交易地址"
     app_id: "你的AppID"
     auth_code: "你的授权码"
   ```

3. 重启交易核心

### Q5: 策略进程占用CPU过高？

**优化建议**：

1. 减少策略中的日志输出频率
2. 优化策略计算逻辑
3. 使用更大的K线周期
4. 限制订阅的合约数量

**示例**：
```python
# 优化前：每个tick都打印日志
def on_tick(self, tick):
    self.logger.info(f"收到tick: {tick.instrument_id}")

# 优化后：每1000个tick打印一次
def on_tick(self, tick):
    self.counter += 1
    if self.counter % 1000 == 0:
        self.logger.info(f"收到tick: {tick.instrument_id}")
```

### Q6: 如何查看系统性能指标？

**Web界面**：
- **控制台**：核心状态、运行时长
- **仪表盘**：CPU使用率、内存占用

**系统日志**：
- EventBus队列深度
- 事件处理延迟
- ZeroMQ消息统计

### Q7: 停止核心后策略仍在运行？

**这是正常的**：
- 停止核心时会自动停止所有运行中的策略
- 如果看到策略仍显示"运行中"，刷新页面即可

**手动停止**：
1. 进入策略管理
2. 逐个停止策略
3. 再停止交易核心

## 安全建议

### 账户安全

1. **修改默认密码**
   - 首次登录后立即修改 `admin` 账户密码
   - 使用强密码（至少8位，包含大小写、数字、符号）

2. **资金账户密码**
   - 不要在代码中硬编码密码
   - 定期更换交易密码

3. **Token安全**
   - Token默认有效期24小时
   - 不要分享Token给他人
   - 定期清理浏览器缓存

### 系统安全

1. **网络隔离**
   - Web服务仅监听本地（127.0.0.1）
   - 生产环境建议配置防火墙
   - 使用HTTPS加密传输

2. **日志管理**
   - 定期清理旧日志文件
   - 不要在日志中输出敏感信息
   - 日志文件权限设置为仅管理员可读

3. **备份策略**
   - 定期备份 `strategy_registry.json`
   - 备份自定义策略代码
   - 备份数据库文件 `homalos.db`

### 交易安全

1. **风险控制**
   - 设置合理的止损止盈参数
   - 限制单笔交易量
   - 监控策略盈亏

2. **测试先行**
   - 新策略先在模拟环境测试
   - 验证策略逻辑正确性
   - 小资金试运行

3. **实时监控**
   - 关注策略运行日志
   - 监控账户资金变化
   - 及时处理异常情况
